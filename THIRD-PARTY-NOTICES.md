# Asset and component notices

Minecraft button sprites, block textures and bitmap glyphs belong to Mojang/Microsoft. `minecraft-ui.woff2` is a pixel-outline conversion of the game's bitmap glyphs for the launcher interface. These assets are not covered by Monkey Client's original-code license. This is an unofficial client, not a Mojang/Microsoft product.

Monkey Client's bundled mod builds each contain their integration notices and license files. They include AppleSkin-derived overlays, Bobby-derived terrain caching, a ShulkerBoxTooltip-derived frame, version-specific unmodified Sodium JARs on Fabric, and MixinExtras on Forge. See the mod source archive and the notices inside each JAR.

The launcher uses Electron, electron-updater, extract-zip and ws under their respective upstream licenses. The installer retains Electron's license files and the application package retains dependency notices.
